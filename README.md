NorthPeak Digital - Responsive Agency Website

Overview

NorthPeak Digital is a modern, responsive one-page digital agency website developed as part of the Digital Heroes Internship Qualification Task. The website is designed using HTML, CSS, and JavaScript with a focus on responsiveness, accessibility, performance optimization, and user experience.

It showcases professional digital services including Web Development, UI/UX Design, SEO Optimization, AI Solutions, Cloud Services, and Digital Marketing.



Features

- Fully Responsive Design
- Modern and Professional User Interface
- Hero Section with Call-to-Action Button
- Six Service Cards
- About Us Section
- Client Testimonials
- Pricing Plans
- Contact Form with Validation
- Smooth Scrolling Navigation
- Hover Effects and Animations
- Accessibility Improvements (ARIA Labels)
- Mobile, Tablet, and Desktop Friendly
- Lighthouse Optimized



Technologies Used
